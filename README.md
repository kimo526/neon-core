# NEON CORE // 解限核心

一个"热管理驱动"的机甲 roguelite 竞技场，支持**本地双人合作**、**弹幕 Boss** 和**极限模式（不回血）**。纯 JS + Canvas，没有依赖、没有构建步骤、没有素材文件。

```
双击 分享给朋友.cmd     # 公网分享：手机 4G/5G 也能开（临时地址，窗口开着就一直有效）
双击 start.cmd          # 本机玩
双击 share.cmd          # 局域网：手机连同一个 WiFi，扫码就进
```

> ES module 在 `file://` 下会被浏览器 CORS 拦掉，所以必须走 http。上面几个脚本都包好了这一步。
>
> 手机上：左半屏拖动移动、右半屏点击冲刺、子弹自动索敌。横屏体验最好。

## 直接分享给别人玩

这游戏是**纯静态站点**——`index.html` + `src/*.js` + 两个图标，没有任何后端。所以任何静态托管都能直接放上去：

| 方式 | 操作 | 得到 |
| --- | --- | --- |
| **公网隧道（手机最稳）** | 双击 `share-online.cmd` —— 自动起服务器 + cloudflared 隧道，终端直接印出地址和二维码 | 一个 `https://xxx.trycloudflare.com` 链接，**手机 4G/5G 也能开**，HTTPS 让 PWA/离线缓存生效 |
| **Netlify Drop** | 打开 app.netlify.com/drop，把整个项目文件夹拖进去 | 固定 https 链接，最快 |
| **Cloudflare Pages** | 连接仓库或直接上传，构建命令留空、输出目录填 `/` | 固定 https 链接 |
| **GitHub Pages** | 见下 | `https://<你>.github.io/neon-core/` |
| **局域网** | 双击 `share.cmd`（或 `node tools/serve.mjs 8787 lan`）——终端会**直接印一个二维码** | 同一个 WiFi 下手机立刻能玩 |

> **手机连不上局域网怎么办？** 先分清楚是谁的问题：跑 `node tools/net-probe.mjs`，它会同时在几个端口监听并打印每一个进来的连接。
> 手机访问后如果**日志一条都没有**，说明数据包根本没到电脑 —— 要么是防火墙（右键 `fix-phone-access.cmd` → 以管理员身份运行），要么是路由器开了"AP 隔离/设备隔离"（这种情况无解，直接用 `share-online.cmd` 走公网隧道）。
>
> 公网隧道是**匿名临时**的：地址每次重启都变，拿到链接的人都能进。玩完关掉窗口即可。

## 玩法模式

| 模式 | 入口 | 规则 |
| --- | --- | --- |
| 标准 | `回车` | 正常回血：nanoswarm 每秒回、残骸回收击杀回、复合装甲立刻修 |
| **极限** | `X`（双人极限 `C`） | **结构值不可回复**。所有回血一律转成护盾（上限 30），大奖也只给护盾 + 3 秒无敌 |

极限模式里"回血卡"不是废卡——它们变成护盾来源；但你也**绝对不可能靠它们续命**。AI 实测：标准模式跑 200 秒还满场飞，极限模式平均 112 秒就撑不住了。血量低于 30% 时 HUD 会闪红、音效会给心跳声。

## 玩什么

**核心机制是热量。** 按住扳机时**完全不散热**，热量满了会锁枪，散热期间还会额外减速。所以这游戏不是"按住左键"，而是一口气打空 → 松手散热 → 再打一波的节奏。热量超过 75% 屏幕边缘开始泛红，机体颜色也随热量偏红——不看 HUD 也能感觉到自己快烧穿了。

清掉一波给三张强化卡，卡池 21 张，偏向**改变玩法**而不是纯数值。

**冲刺构筑（6 张，互相叠加成一套完整打法）**：相位脉冲（冲刺穿敌触发脉冲，起点）→ 相位刀锋（冲刺伤害 ×2.5）→ 熔核尾迹（路径留下灼烧区）→ 急停爆发（冲刺结束打出一圈弹幕并返还充能）→ 连锁冲刺（击杀返还冷却，杀得越多冲得越勤）→ 反射装甲（冲刺得护盾）→ 破空（起步震住身边敌人）。凑齐之后你会**不再靠枪输出**——冲进去、炸一圈、再冲出来。

其他方向：超载核心（射速换热量）、弹射协议（子弹打墙反弹）、引力锚（站桩散热翻倍）、强制排热（过热时放环形冲击波）……

**特殊攻击「超载回满」（0.1%）**：每次攻击命中有千分之一概率触发——机体爆出一圈红黑特效（黑闪电 + 全屏红黑闪 + 机甲自身红黑同心环 + 压低失真的"超载回满"播报），并把状态**全部拉满**：血量、护盾、热量清零、冲刺充能、外加一小段无敌。实测 AI 火力下平均**每 3 分钟**出一次，也就是说这基本是一局见一回或两局见一回的东西。HUD 上有一行"超载"记你中过几次。

**双人合作的规则：** 敌人数量 ×1.7、血量额外加成，但敌人会**优先锁定最近的玩家**——所以"谁上去拉仇恨、谁在后面输出"是天然形成的。队友倒地后有 5 秒归队倒计时，两人同时倒才算团灭。两人各自独立的热量、冲刺、强化卡，战报也是分开算的（谁抢到的击杀算谁的）。

## 弹幕玩法（雷霆战机 / 东方那一路）

每 **5 波**来一个**弹幕核心（Boss）**：有血条、分三阶段，血量跌破阈值就换招式。它不靠"子弹多"压人，靠**成体系的弹幕**——每种弹幕都有自己的读法：

| 招式 | 读法 |
| --- | --- |
| 螺旋 | 慢速旋转的弹链，读的是"缝在哪" |
| 环形爆发 | 一圈慢弹 + 一圈快弹，找两层之间的空档 |
| 自机狙 | 带预判的扇射，别走直线 |
| 弹墙 | 密弹里留一个旋转缺口，必须钻缝 |
| 米字弹 | 节奏固定的八向爆发，惩罚站着不动 |
| 追踪弹 | 慢慢转弯，逼你走位而不是原地微调 |

**擦弹**是这套玩法的核心：子弹贴着机体飞过（26px 内）而不命中，就会积攒**擦弹充能**——攒满自动补 1 段冲刺 + 12 护盾 + 0.35 秒无敌。所以"贴着弹幕走"是有收益的，这也是东方最上瘾的那部分。

**侧边操作提示面板**（画布右侧）常驻显示两套按键，并且是**活的**：Boss 血条、擦弹充能条、每个人的擦弹数与冲刺冷却、特殊攻击的当前概率和已触发次数。窄屏（<980px）会自动折到画布下方变成两列。

## 声音

没有任何音频文件，**全部是 WebAudio 现场合成**：

- **枪声**：激光音高随开枪者的热量上移，越烫越尖；霰弹是低频噪声闷响
- **热量底噪**：一条常驻带通噪声，滤波频率随温度升高，过热时变响
- **过热警报**：每 0.45 秒一声高频提示音
- **特殊攻击**：低频轰鸣 + 五声金属泛音 + 长尾噪声，0.1% 的中奖必须有排面
- **机器人播报**：`第 N 波` / `清空` / `过热` / `断连` / `超载回满` / `战斗失败`——这是自己写的**共振峰合成器**（每个字 = 声母噪声爆破 + 双共振峰韵母 + 音高曲线），不是外部 TTS

> 为什么播报要自己合成：这台开发机上既没有 TTS 的 API key，也没有 python/ffmpeg，而"第 N 波"这种战场播报恰恰最能提升节奏感。于是用共振峰硬拼了一个能听懂的机甲音色，全离线、零依赖、不占体积。

## 代码结构

```
src/content.js    数值与内容：手感参数、武器、敌人、合作缩放、特殊攻击概率、擦弹参数、模式定义
src/patterns.js   弹幕模式库：螺旋/环形/自机狙/弹墙/米字/追踪 + Boss 分阶段时间线
src/upgrades.js   强化卡池 + 抽卡（含冲刺构筑 6 张）
src/sim.js        纯逻辑模拟：step(world, inputs, dt)，不碰 DOM
src/bot.js        会走位/预判/管理热量的 AI（就是按 G 出场的那个）
src/harness.js    无头对局跑分（Node 与浏览器共用）
src/render.js     Canvas 渲染（多人、热量色偏、尾迹、弹幕贴图缓存、红黑超载特效）
src/hints.js      侧边操作提示面板（静态按键 + 实时 Boss 血条/擦弹充能）
src/audio.js      音效合成 + 混音总线
src/voice.js      共振峰机器人播报
src/input.js      键鼠 / 触屏 → input 对象（单人 / 双人 / 触屏三套映射）
src/main.js       主循环、多玩家 HUD、界面状态机、PWA 注册、window.NEON 调试钩子
sw.js             离线缓存（Service Worker）
manifest.webmanifest + assets/   PWA 清单与图标
tests/            62 个测试：机制、边界、合作、冲刺构筑、特殊攻击、弹幕、极限模式、平衡、长跑
tools/            静态服务器 / 平衡台 / 触发率实测 / 无头截图验收 / 图标生成
```

关键设计：**逻辑层是纯的**。`step(world, inputs, dt)` 只依赖传入的 world 和输入，人类和 AI 走同一个 input 接口，所以 AI 跑出来的平衡数据对人类有意义，也能跑"两个 AI 合作"来验证双人难度。

```bash
node --test tests/*.test.js                        # 69 个测试（含二维码往返解码自验证）

node tools/simulate.mjs 1,2,3,4,5,6,7,8 300 2      # 双人平衡台

node tools/headless.mjs solo 30 --boss             # 召出弹幕 Boss，弹幕最密时截图
node tools/headless.mjs solo 20 --proc=0.05        # 强制特殊攻击，专截红黑特效
node tools/make-icon.mjs                           # 重新生成 PWA 图标（零依赖，手写 PNG 编码）
```

`src/qr.js` 是个零依赖的二维码编码器（版本 1–6、字节模式、纠错 M），用来印局域网分享码。
它自带一个**解码器测试**（`tests/qr.test.js`）：把编出来的码解回原文比对，再校验 Reed-Solomon
纠错自洽、格式信息、三个定位图形和定时图形——二维码最容易"看着对但扫不出来"，所以必须端到端验。

改手感只需要动 `src/content.js` 里的 `TUNING` / `WEAPONS` / `ENEMY_TYPES` / `COOP` / `GRAZE` / `MODES`；想加新弹幕就往 `src/patterns.js` 的 `PATTERNS` 里加一条（`{ name, cd, fn }`）。

`tools/headless.mjs` 是给自己用的验收工具：它用 Edge 的 DevTools 协议开无头页面、点开始、让 AI 托管、抓页面报错、最后截一张 1280×760 的实机图（`headless-*.png`）。不需要装 Playwright——Node 自带 WebSocket，走 CDP 就够了。

浏览器里还有 `window.NEON` 调试钩子：`NEON.debug()` 看状态、`NEON.setSpeed(4)` 加速、`NEON.bot.on()` 托管、`NEON.voice.announce('wave', 3)` 单测播报、`NEON.setProcRate(1)` 让特殊攻击每发必中（试特效）、`NEON.forceProc()` 直接触发一次。

## 平衡基线

AI（会预判瞄准、会拉距离、热量到 72% 主动松手；P2 用"方向键八向瞄准"所以更弱）在 8 个种子上跑 300 秒：

| | 平均清波 | 平均击杀 | 命中率 | 300 秒阵亡率 |
| --- | --- | --- | --- | --- |
| 单人 | 10.6 | 194 | 97% | 0% |
| 双人 | 8.5 | 233 | 83% | 13% |
| **极限单人** | — | — | — | 同种子下 112 秒 vs 标准 200 秒 |

双人的 13% 阵亡率基本来自弹幕核心——**Boss 是这游戏目前唯一能真正杀死 AI 的东西**，说明弹幕那套压力是有效的。极限模式则直接砍掉了"续航"这个维度：AI 在同种子下从 200 秒掉到 112 秒，人类会更明显。

人类成绩通常会低于这个数（AI 的预判瞄准很准），所以能活过 AI 说明打得不错。目前 AI 在 300 秒内基本不会死，也就是说**难度还有上调空间**——想加难度就改 `COOP.enemyBonus` 和 `ENEMY_SCALING`。
